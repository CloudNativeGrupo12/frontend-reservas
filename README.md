# frontend-reservas

Frontend Angular para EP3 DSY1107. **[Probar la aplicación en AWS](https://6yyp6d2s6j.execute-api.us-east-1.amazonaws.com)** e iniciar sesión con Microsoft del tenant institucional configurado.

La aplicación y las cinco APIs están desplegadas en AWS con HTTPS y bases RDS. El código de Angular está en [`frontend-reservas/`](frontend-reservas/); consultar su [guía](frontend-reservas/README.md) y la [configuración Azure y producción](frontend-reservas/docs/CONFIGURACION-AZURE.md).

La entrega se encuentra en la rama `feature/ep3-rubrica` de ambos repositorios. La infraestructura y las evidencias están en [el backend](https://github.com/CloudNativeGrupo12/actividad-evaluada-rabbitmq/tree/feature/ep3-rubrica/docs/DESPLIEGUE_AWS.md).
